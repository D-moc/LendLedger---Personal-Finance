# LendLedger — Personal Finance

LendLedger is a web-based personal finance platform that helps users manage money they have given, borrowed, and repaid in one organized place.

## Features

- User registration and login
- Secure authentication
- Manage people
- Track money given and borrowed
- Track payments and outstanding balances
- Interest tracking
- Search and filter records
- Archive and restore people
- Financial reports and summaries
- Password reset functionality
- Responsive and minimal UI

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Tailwind CSS
- Recharts
- Lucide React
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
